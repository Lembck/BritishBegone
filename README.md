# BritishBegone
A Chrome/Brave extension that converts British spellings to American spellings on any website with a single click.

## Features
- Works on any website (not limited to specific domains)
- Converts British spellings to American equivalents
- Shows a badge counter indicating how many words were replaced
- Simple one-click activation
- Reverses changes by reloading the page

## Installation
1. Download or clone this repository
2. Open Chrome/Brave and navigate to `chrome://extensions/`
3. Enable "Developer mode" in the top right
4. Click "Load unpacked" and select the extension folder
5. Pin the extension for easy access

## Usage
1. Navigate to any website
2. Click the BritishBegone extension icon in your toolbar
3. British spellings will automatically be converted to American spellings
4. The badge will display the number of words replaced
5. Reload the page to undo changes

## Note
The extension uses word-for-word replacement and doesn't consider context, which may occasionally produce unexpected results.
